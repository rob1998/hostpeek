# Changelog

Notable changes to Hostpeek are recorded here.

## [0.1.0] - 2026-09-30

### Added

- First Hostpeek release with a cPanel setup wizard for application, database and branding settings.
- Create hostname-preserving website previews through a selected destination IP.
- Password-protected preview management with editable expiration, optional preview passwords, search, sorting and pagination.
- Configurable branding, preview domain, timezone, target connection settings and redirect behavior.
- Deployment-ready release package with production dependencies included.
