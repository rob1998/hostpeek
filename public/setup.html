Introduction

Prepare your hosting

  1. Point your domain and its wildcard to this server. For preview.example.org, also add *.preview.example.org.
  2. Set both document roots to this application's public/ folder. Keep the other files one level above it.
  3. Install an SSL certificate covering both names. With external DNS, wildcard validation may need a DNS TXT record.
  4. Open Manage My Databases or MySQL Databases. Create a dedicated database and user, add the user to that database, and grant all privileges.
