Configuration

Where do I change the settings?

Open config.php in your cPanel File Manager. It sits beside public/, outside the public web folder. Save a backup before changing it. The main settings are:

  • name, logo_light, logo_dark and favicon control the service branding.
  • base_url is the public address. Its DNS, document root and certificate must cover the base hostname and wildcard.
  • upstream_scheme sets the default for bare hostnames. A pasted HTTP or HTTPS URL overrides it for that preview.
  • allow_self_signed controls certificate checks when connecting to HTTPS targets.
  • preview_ttl sets the default lifetime. Each preview can have its own expiry under Advanced.
  • timezone controls date and time entry and display.
  • manage_password protects creation and management.

Logo and favicon files belong in public/assets/; use paths such as /assets/logo.svg. Keep the database password and hash_secret private. The hash secret should stay stable after setup.

Where do I find the database details?

In cPanel, open MySQL Database Wizard (or Manage My Databases). Create a database and a database user, then grant that user privileges on the database. Put the database host, full cPanel-prefixed name, username and password in config.php. On most cPanel hosts the database host is localhost.

How do I change the default expiry or timezone?

Set preview_ttl in seconds; 3600 means one hour from creation. For timezone, enter the name for your region, such as Europe/Amsterdam. Find yours in the official list of supported timezones. Changing these settings does not change when existing previews expire.

Troubleshooting

The service or wildcard preview does not open.

Check that DNS records for both the base hostname and * point to this hosting account. In cPanel, both hostnames must use the service's public/ folder as their document root, and the installed certificate must cover the base and wildcard names. DNS changes can take time to appear.

The preview shows a certificate error or the wrong target page.

The target hostname is sent to the server at the destination IP, including as TLS SNI for HTTPS. Check that the target hosting account has that hostname configured and serves it at the selected IP. allow_self_signed only skips certificate verification for target HTTPS connections; it does not fix the target's virtual-host configuration or change the preview domain certificate.

What does the HTTPS setting do?

upstream_scheme is the default when entering a hostname without a protocol: https uses port 443 and http uses port 80. Pasting an HTTP or HTTPS URL selects that protocol for the preview. For HTTPS targets, allow_self_signed set to false verifies the target certificate; true also accepts invalid or mismatched certificates.

Some images, styles or links do not work.

The preview extracts the hostname from your URL and rewrites links for that hostname. Websites that load assets from other hostnames, build URLs dynamically in JavaScript, or rely on browser APIs such as service workers may need adjustments to work through a preview.

Forms or sign-in on the target site do not work.

The relay supports browsing with GET and HEAD requests. It does not forward form submissions or other request methods, so target-site sign-in, checkout and other write actions are not available.

Why did I have to sign in again?

You are signed out automatically after a period of inactivity, usually 24 minutes. The exact time depends on your hosting settings. Searching, switching pages in the management area or saving a preview restarts the timer. Leaving the page open or browsing a preview does not.

Can search engines index preview pages?

Preview responses include no-index headers, and the wildcard robots.txt disallows crawling.
